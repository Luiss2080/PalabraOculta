# 🎯 Manual de Usuario: PalabraOculta

## ¿Qué es?
PalabraOculta es una versión moderna del clásico juego de adivinar palabras, construido con React, Vite y Framer Motion para asegurar una experiencia interactiva fluida.

## ¿Cómo Jugar?
1. Al iniciar la aplicación, se elegirá una palabra aleatoria de una categoría predefinida (ej. Animales, Frutas, Países).
2. Debes adivinar las letras que componen la palabra antes de que se dibuje el ahorcado por completo.
3. Puedes hacer clic en el teclado virtual o teclear directamente en tu teclado físico.
4. **Racha (Streak):** Ganar partidas consecutivas aumenta tu racha. Perder una partida la reiniciará a cero.

## Ajustes
En el icono de engranaje (⚙️) puedes:
- **Cambiar el Tema:** Alternar entre Modo Claro y Oscuro.
- **Cambiar Dificultad:**
  - **Fácil:** Tienes hasta 8 fallos permitidos.
  - **Normal:** Tienes 6 fallos (clásico).
  - **Difícil:** Solo 4 fallos (para expertos).

## Tecnologías Usadas
- React + Vite
- Framer Motion (Animaciones)
- Lucide React (Iconos vectoriales)
- React Confetti (Celebración al ganar)
- CSS Variables para el Theming (Glassmorphism)
