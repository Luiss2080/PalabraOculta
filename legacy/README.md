# 🎯 Ahorcado

El clásico juego del Ahorcado en español, con categorías (frutas, animales,
países, profesiones) y dibujo SVG animado. HTML/CSS/JS puro, sin dependencias.

Gratis para usar, modificar y regalar. Fácil de extender: agregá tus propias
categorías/palabras en el objeto `PALABRAS` de `script.js`.

## Jugar

Abrí `index.html` en el navegador, o serví la carpeta con cualquier servidor
estático (GitHub Pages, Netlify, `npx serve`).
